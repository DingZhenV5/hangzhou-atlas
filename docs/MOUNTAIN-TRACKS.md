# hangzhou_mountain 坐标资料核查与试画

核查日期：2026-09-30。来源：[仓库 README](https://github.com/smasterfree/hangzhou_mountain)、[热门路线目录](https://github.com/smasterfree/hangzhou_mountain/tree/main/%E5%8E%9F%E5%A7%8B%E6%95%B0%E6%8D%AE/%E7%83%AD%E9%97%A8%E8%B7%AF%E7%BA%BF)。

## 仓库里分别有什么

| 目录或文件 | 内容 | 适合的用途 |
| --- | --- | --- |
| `Readme.md`、`热门路线/hotlines.json` | 主干线、短线、赛事和野路的文字说明与概数 | 发现候选路线、起终点、看点；`hotlines.json` 本身没有路线折线坐标 |
| `热门路线/*.txt` | 按顺序排列的 `经度,纬度` 数值点，空格分隔 | 可试画路线弯折；先核对坐标系、端点、异常跳点和现今通行 |
| `路线坐标/*.json` | `style` 与 `trackLine`，记录更细的主干、支线等线段 | 将来可用于分段拼接和识别岔路；不能仅靠文件名自动推出完整路线 |
| `山峰和入口坐标/*.json` | 山峰、入口的名称、经纬度及海拔字段 | 补入口、山峰标注；位置和海拔仍需与现今资料核对 |
| `map/`、`images/` | 手绘、纸质扫描、旧地图和 App 截图 | 人工辨认地形、山峰与路线关系；图片没有可直接叠加到底图的地理配准 |

README 说明其坐标主要从旧登山 App 提取，App 又参考纸质图、公开轨迹和实走记录。仓库没有给热门路线文本明确标注坐标系或最新通行日期。手绘图适合与文字互相参照，不能从像素直接推算高德坐标。[西湖登山图 2002](https://github.com/smasterfree/hangzhou_mountain/blob/main/map/%E8%A5%BF%E6%B9%96%E7%99%BB%E5%B1%B1%E5%9B%BE2002.jpg)上可辨认宝石山、葛岭等地名，但它不是电子轨迹。

## 黄龙洞至宝石山试画

- 本地保留 [来源坐标文本](../data/source-tracks/huanglong-baoshi.txt)，对应[仓库原文件](https://github.com/smasterfree/hangzhou_mountain/blob/main/%E5%8E%9F%E5%A7%8B%E6%95%B0%E6%8D%AE/%E7%83%AD%E9%97%A8%E8%B7%AF%E7%BA%BF/%E9%BB%84%E9%BE%99%E6%B4%9E%E8%87%B3%E5%AE%9D%E7%9F%B3%E5%B1%B1.txt)。37 个来源点已用于现有「黄龙洞到宝石山」路线，地图只显示黄龙洞入口和宝石山下一弄出口两个编号站点。
- 来源首点距高德黄龙洞 POI 约 27 米；终点距「保俶路与宝石山下一弄交叉口」POI 约 17 米；保俶塔 POI 距曲线约 10 米。由此推断与高德 GCJ-02 坐标大致相容，仍需用更多路段和实地轨迹确认。
- 来源文字称约 2 公里，37 点的顺序距离约 3.1 公里。页面把里程标成坐标估算并显示差异；没有改写为已实测路程。
- 地图试画能显示山路弯折，入口、保俶塔附近、出口与底图视觉上接近。高德底图未显示所有山间小径，视觉接近不足以证明沿线可通行。

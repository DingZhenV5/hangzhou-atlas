# V1 数据与维护约定

V1 是静态网页：页面由 `site/` 构建，地点与路线保存在 JSON 中。无需数据库或运行中的后端；本地编辑数据、构建后即可检查效果。公开访客不能直接写回仓库。

## 地点

在 `data/places.json` 中新增地点时，填写唯一 `id`、名称、区县、分类、主题标签、GCJ-02 坐标、简短介绍、看点、推荐理由、建议停留时间和来源链接。高德评分是带核对日期的快照，缺失时留空。

## 路线

在 `data/routes.json` 中新增路线时，填写唯一 `id`、路线类型、地区、建议用时、参考里程、难度、介绍、推荐理由、站点 ID、绘制坐标和来源。站点必须能关联到 `data/places.json` 中的地点。

路线坐标须区分资料轨迹与示意线。未实地或按可靠轨迹逐段核对的折线只用于地图浏览，不作导航、距离保证或安全判断。

## 本地检查

```powershell
node tools/build.mjs
node tools/preview.mjs
```

在浏览器检查地点落点、路线顺序、来源链接和手机布局。构建检查数据格式、引用关系和来源字段。

## 发布边界

高德安全密钥、浏览器配置、本地采集文件和未整理的研究材料放在被忽略的本机目录。准备公开前，逐项检查仓库文件、Git 历史、地图数据的来源及路线使用许可；GitHub Pages 只发布明确放入构建目录的静态页面文件。

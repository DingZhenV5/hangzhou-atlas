该仓库的脚本在缺少距离、时间或点赞数时会按节点数、搜索结果顺序生成估计值，并给旧路线刷新 `updated` 日期；这些字段不能直接当作实测里程或真实点赞。网页加载仓库内的 `routes.json`，不是浏览器实时请求小红书。Python 中能解析动态 JSON 的库属于另一种直接采集方案，本轮没有接入。

难度目前是编辑估计，依据是公开参考里程、路线节点和是否连续登高。新增路线只提供浏览用站点连线，不能按线寻路。若取得可靠轨迹，应保留轨迹出处、坐标系与复核日期，并逐段与地图上的可通行步道比对。
